# Person 1 status

## Current phase: Phase 1 offline complete, Atlas checks pending

P1 owns backend core, capture ingest, sessionization, mining, policy defaults, data generation, seeding, and later runtime/search/metrics work. The updated board is `TASKS_3people (1).md`, linked from `docs/TASKS.md`.

The implemented path runs end to end in fixture or in-memory mode: synthetic observations are normalized, redacted, mapped to canonical signatures, sessionized with a 30-minute gap, mined with a bounded PrefixSpan pass, scored against hard gates, and seeded through the API batch endpoint. Live Atlas verification is intentionally still open until MongoDB access is available.

## Commands

Run from the repository root:

```sh
.venv/bin/python -m pytest -q
.venv/bin/ruff check backend scripts data
.venv/bin/ruff format --check backend scripts data
.venv/bin/python -m data.generator --out /tmp/toolsmith-seed
.venv/bin/python scripts/seed.py --directory /tmp/toolsmith-seed --api http://localhost:8000 --reset
.venv/bin/python scripts/seed.py --directory /tmp/toolsmith-seed --api http://localhost:8000 --logs-only --reset
```

Atlas-only commands for the next step:

```sh
.venv/bin/python scripts/init_db.py
.venv/bin/python scripts/verify_atlas.py
.venv/bin/python scripts/search_indexes.py --text-dims 1024 --frame-dims <verified-dims> --apply
```
