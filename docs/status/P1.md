## Local setup

Run from the repository root:

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r backend/requirements/dev.txt
cp .env.example .env
.venv/bin/pytest -q
.venv/bin/ruff check backend scripts
```

Start the API from `backend/`:

```sh
../.venv/bin/uvicorn app.main:app --reload
```

`GET /tools` returns the sample tool; `POST /capture/batch` accepts the capture
fixture. `/docs` exposes the implemented routes. All application routes are fixture
stubs at this phase; `STUB_MODE=false` prevents accidental fixture fallback.
This is a single-user local demo scaffold, without production authentication.

P2 routers are discovered as `app/routers/p2_*.py` exposing `router`. Job handlers
register through `from worker import register`, with signature
`async def handler(payload: dict)` in `app/<module>/jobs.py`. Duplicate registration
of different handlers fails explicitly. The worker does not consume Atlas jobs yet.
